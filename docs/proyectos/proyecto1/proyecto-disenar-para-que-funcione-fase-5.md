## **Fase 5: Mapear los user flows**

Una pantalla puede estar bien resuelta y aun así formar parte de un flujo que no funciona. Por eso se mapea antes de dibujar.

#### **Qué tienes que hacer:**

Identifica las tres a cinco tareas críticas de tu producto: las que sin ellas la aplicación pierde el sentido. Para cada una, mapea el flujo completo en FigJam con la notación estándar: píldora para el punto de entrada o salida, rectángulo para cada pantalla o estado, rombo para cada decisión, flechas para las transiciones.

Mapea siempre el happy path primero, y después al menos dos o tres casos límite por flujo: qué pasa si la contraseña falla, si se corta la conexión a mitad de un pago, si alguien vuelve a un proceso a medias. Recorre cada flujo con tus personas como filtro, en especial la de diversidad funcional, y anota las decisiones que queden abiertas.

#### **Entregable:**

User flows de las tareas críticas, con happy path y casos límite anotados.
